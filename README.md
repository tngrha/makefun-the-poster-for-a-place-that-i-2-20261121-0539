**SOLMARA** — a travel poster for a place that isn't there. A harbor town built along the rim
of a colossal sleeping sea-turtle's shell, at dusk: lit windows, a striped lighthouse with a
sweeping beam, a lantern-strung market quay with awning stalls, a wooden dock with a fisher,
and fishing boats with warm lamps on a calm amber sea. The invented name is the only text.

Pure Python 3.13 standard library: a hand-rolled RGB framebuffer, an original bitmap font,
flat geometric shapes and a hand-written PNG encoder. No network, no randomness — two runs
are byte-identical.

## Run it

```sh
python3 main.py            # writes /output/entry.png (1024x1024 PNG)
python3 main.py poster.png # or to a path of your choice
```
